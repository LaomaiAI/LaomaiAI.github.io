Skill：单模型三角色分工（一个对话框顶一个团队）

版本：v1.0 | 核查日期：2026-10-19 | 适用：任何支持多轮对话的模型网页版 / App 对话框

对应长文：《免费获取三 Agent 分工提示词模板：一个对话框顶一个团队，事半功倍》

一句话方法

同一个模型，在一次对话里依次扮演三个角色：规划 Agent 先拆任务定标准，执行 Agent 按步骤干活留证据，审核 Agent 对照标准挑毛病。审核不通过，打回重做，直到通过。

免费点与边界（核查日期 2026-10-19，来源见文末）

  • DeepSeek：官网下载页口径为“免费体验与全球领先 AI 模型的互动交流”。注意：官方写的是“免费体验”，不是“无限量”。正文里不许把“免费体验”扩写成“长期免费无限量”。
  • 智谱网页版（chat.z.ai / z.ai）：本次核查在官方页面文本中未确认明确的“免费”口径表述（2026-10-19 复核抓取尝试超时，未取回页面文本；此前无抓取日志留存）。结论：写“未核实”，不许写成“官方宣称免费”。
  • 阿里百炼：不是免费对话。它是 API 平台，模型调用默认按量计费；官方价目表显示部分模型在华北 2（北京）地域有免费额度（例如多款模型为 100 万 Token，有效期自开通 / 模型发布 / 申请通过之日起 90 天内，以较晚者为准）。使用百炼需要阿里云账号与 API Key。不要把百炼的“免费额度”说成“网页版免费对话”。
  • 严禁说法：某已作废的 DeepSeek 新号赠送额度说法，任何地方不许出现该说法或类似未经核实的赠送额度数字。第三方营销文声称的赠送额度数字不是官方口径，不许当官方来源引用。

三角色提示词模板全文（直接复制使用）

把下面三条提示词，按顺序发在同一个对话框里。上一条出结果后，再发下一条。

第 1 条：规划 Agent

你现在是规划 Agent。任务：{用一句话写清任务}。
只出计划，不执行任务。输出三部分：
1) 步骤拆解：不超过 5 步，每步一句话。
2) 每步的验收标准：必须可检查，不含“尽量”“大概”“差不多”这类词。
3) 证据要求：每步交付什么文件 / 链接 / 截图，写清楚。
计划末尾写：计划已出，等待执行指令。

第 2 条：执行 Agent

你现在是执行 Agent。按上面规划的步骤执行。规则：
1) 一步一步来，每步输出结果加证据。
2) 每个数字、每个“免费”说法，必须有来源，来源写清页面 URL 与查看日期。没跑过的写“未实测”，不许写成跑过。
3) 遇到规划没覆盖的情况，停下并写清问题，不擅自改规划。
全部步骤完成后写：执行完毕，等待审核。

第 3 条：审核 Agent

你现在是审核 Agent，与执行无关。你手里有规划的验收标准和执行的结果。逐条对照：
1) 每步是否达标。
2) 每个数字、“免费”说法是否有官方来源。
3) 是否有编造、扩写、偷换概念。
输出：通过项 / 不通过项（每项写清证据）/ 修改意见。
最后给结论：通过，或打回重做（写清重做哪几步）。

使用流程

  1. 同一个对话框，先发第 1 条，拿到计划。
  2. 再发第 2 条，拿到执行结果与证据。
  3. 再发第 3 条，拿到审核结论。
  4. 审核“通过”：归档，任务结束。
  5. 审核“打回重做”：只重做不通过的步骤，已通过步骤的证据保留，不推倒重来。
  6. 执行中卡住（规划没覆盖的情况）：回到第 1 条，收窄任务范围，重新规划。

检查清单（执行前逐项打勾）

  • ☐ 任务一句话写清了，没有“大概做一下”这类模糊表述
  • ☐ 规划不超过 5 步，每步有可检查的验收标准
  • ☐ 每个数字、“免费”说法都标了官方来源 URL 与查看日期
  • ☐ 没跑过的写了“未实测”，没有写成跑过
  • ☐ 审核角色与执行角色分离：审核没有直接复述执行结论，每项都对照了验收标准
  • ☐ 审核打回时，写清了重做哪几步，没有全盘推倒
  • ☐ 敏感数字（如赠送额度）逐个核对过官方页面，没有引用第三方营销文

正例子（本次演示任务的真实输出摘要）

任务：调研并核实国内主流大模型官方免费入口现状（DeepSeek 网页版、智谱 GLM、阿里百炼），输出带官方来源的核查简报。演示在生产会话内按模板逐角色执行，未在 DeepSeek 网页版内粘贴运行，网页版复现指南见本 Skill 复现指南。

  • 规划输出：3 步（列 claim 清单；逐条对照官方页面核查；出带来源简报）。验收标准：每条 claim 有官方 URL 与核查日期；无法核实的写“未核实”。
  • 执行输出：DeepSeek 官网下载页“免费体验”；百炼官方价目表“按量计费 + 部分模型华北 2 有 100 万 Token 免费额度，90 天有效”；智谱官方页面未提取到明确免费口径，记“未核实”。
  • 审核输出：抓出四个错误并打回修正。其一，初稿把 DeepSeek“免费体验”扩写成“长期免费无限量”，纠正为照抄官方原话“免费体验”。其二，初稿把智谱“未核实”写成“智谱网页版免费”，纠正为“未核实”，不写“免费”。其三，初稿把百炼写成“免费对话”，纠正为“API 免费额度，不是免费对话”；初稿引用的第三方营销文声称的赠送额度数字删除、不写，官方价目表的 100 万 Token 免费额度保留。其四，初稿 claim 清单中“百炼免费，免费额度很高”，“很高”不可检查，改为可检查表述。修正后通过。

反例子（不要这样做）

  • 反例 1：执行把“免费体验”写成“长期免费无限量”。问题：扩写官方口径，属于编造。正确做法：照抄官方原话，并注明来源。
  • 反例 2：把第三方营销文声称的赠送额度数字写进简报当官方口径。问题：来源不是官方。正确做法：只认官方页面（help.aliyun.com 等），第三方说法一律不采信。
  • 反例 3：审核只写“看起来没问题，通过”。问题：审核与执行同一口径，角色未分离。正确做法：逐条对照验收标准，每项写清证据。
  • 反例 4：审核打回后，把已通过的核查全部重做一遍。问题：浪费。正确做法：只重做不通过的步骤。

失败回滚

  • 审核打回：保留已通过步骤的证据，只重做不通过步骤，并在记录里写清改了什么。
  • 执行卡住：停下，写清卡在哪一步、缺什么信息，回到规划收窄范围，不硬编结果。
  • 来源不可靠：把该条结论降级为“未核实”，保留核查过程记录，不删除、不掩盖。
  • 模型把角色混了（例如执行时自己给自己“通过”）：重新发第 3 条审核提示词，并加一句：“你只做审核，不执行，不复述执行结论。”

复现指南（未实测部分请按此复现，不要写成跑过）

  1. 打开 DeepSeek 官网下载页（https://www.deepseek.com/download/），核对“免费体验”表述。
  2. 打开智谱网页版（https://chat.z.ai/），在页面内寻找官方“免费”口径表述；如找不到，结论就是“未核实”。

  4. 把三条提示词按顺序发进同一个对话框，跑一次你自己的真实任务，保存完整记录。
