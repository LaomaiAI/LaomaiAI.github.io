Skill：防封号指南（只做有来源的事）

来源：08《新号别乱动：这份防封号指南，先保住你的号》+ 长文来源清单 1–14。

本 Skill 不提供无来源的逐日养号数字、发帖频率安全值、IP/设备隔离步骤、申诉时限与通过率。没有来源的，不写。不确定的，以平台官方规则为准。

直接把下面的提示词丢给你的 Agent，即可使用这个 Skill。先过操作清单，再看提示词，最后按失败回退模板写验收标准。

什么时候用这个 Skill

新号启动、准备发内容、准备接第三方工具、准备做多账号、收到警告/限流/封禁通知时用。目标：发之前先排雷，被封后只走官方入口。

核心原则

  • 很多封号是踩了写明的红线：非 API 自动化、批量互动、同质化重复、冒充与买卖互动量、关联连坐。
  • 流传的逐日养号数字清单没有官方来源，不要照着抄。微信官方已辟谣所谓“封号新规”。
  • 自动化只走官方 API；申诉只走官方入口。

一、操作清单（照着做）

第 1 步：发之前先读官方规则

  1. X：开发者政策与真实性规则；抖音：社区自律公约；微信：《微信个人账号使用规范》；小红书：社区金融生态公约。
  2. 读不懂的，先停手，不要靠传言猜。

第 2 步：排掉自动化风险

  • 不用脚本、爬虫、浏览器自动化代替 API。非 API 自动化可导致永久停用。
  • 不接来路不明的第三方工具帮你自动发、自动回、自动关注。
  • 自动化回复 / 私信先取得对方明确同意，并尊重退订要求。
  • 机器人账号在简介中说明自己是机器人以及负责人，不要冒充真人。

第 3 步：排掉批量与同质化风险

  • 不批量关注 / 点赞 / 回复 / 私信；不做跟随-取关循环。
  • 不多账号发相同或近似内容；不多账号互相刷量、互相导流。
  • 不买粉、买赞、买转发，不付费请服务商代刷。
  • 不搬运未授权内容；不虚假宣传。

第 4 步：排掉多账号关联风险

  • 每个账号有自己的身份、目的与内容。
  • 一个账号违规后，不要换关联账号继续发同一套违规内容。
  • 矩阵账号不要用来规避审核、逃避处罚、扩散违规内容。

第 5 步：金融内容先看资质

  • 无牌照、无平台认证，不做金融营销。
  • 不做非法荐股、伪造资质、保本保息承诺、虚假人设、违规导流。
  • AI 生成内容要标注；要做风险提示。

第 6 步：收到警告先停手

  • 梯度处罚意味着小处罚是升级的前兆。
  • 先清理违规内容，再走官方申诉入口，不要继续发。

第 7 步：被封后申诉

  1. 看通知：记下平台告知的政策与内容。
  2. 删违规：清理仍在的违规内容。
  3. 先看验证提示：登录被封账号，如有手机 / 邮箱验证提示，先完成验证（可直接解封，无需申诉）；无验证提示、且认为是误判时，再走申诉表单。
  4. 走官方入口：X 为帮助中心申诉表单；抖音为 App 内账号封禁申诉入口。
  5. 如实说明：按平台要求填写身份信息、说明情况并附相关证明，不编造经过。
  6. 等回复：X 帮助页未公布申诉处理时限，本 Skill 不编造天数。

二、提示词（可复制）

你要帮我做一次防封号检查。只依据我给你的平台官方规则与公开来源，不要编造数字、时限、案例与个人经历。没有来源的，明确说“没有来源”。

账号情况：[平台 / 新号还是老号 / 是否接第三方工具 / 是否多账号 / 内容类型]
我要做的操作：[发内容 / 自动回复 / 批量互动 / 多账号发布 / 金融内容，选一并写具体做法]

请按下面输出，不要直接说“没问题”：
1. 这项操作触碰了哪条有来源的红线？写出来源编号。
2. 哪些说法是我从传言听来的、没有官方来源？逐条指出。
3. 改成合规做法：每条改法都要有来源编号，没有来源的不要写。
4. 发之前检查表：逐项打勾，打不上勾的先停手。
5. 如果已经收到警告/封禁：只写官方申诉入口与如实说明步骤，不编造时限与通过率。

最后给一句话结论：能做 / 改完再做 / 不能做 + 理由。

三、检查项

□ 没有用脚本、爬虫、浏览器自动化代替 API？
□ 没有批量关注 / 点赞 / 回复 / 私信，没有跟随-取关循环？
□ 没有多账号发相同或近似内容？
□ 没有买粉买赞买转发，没有付费代刷？
□ 机器人身份已在简介中说明，没有冒充他人？
□ 没有搬运未授权内容，没有虚假宣传？
□ 没有用外挂批量加好友、群发欺诈信息？
□ 金融内容：有资质、有认证、有风险提示，AI 生成已标注？
□ 账号之间没有互相刷量、互相导流、发同一套内容？
□ 申诉只走官方入口，材料如实填写？

10 个框都打勾，再发。有一个打不上，先停手。

四、常见坑

  • “照着养号日程做就安全”：逐日数字清单没有官方来源，多为传言或黑产话术。
  • “好友太多 / 固定地点会封号”：微信官方已辟谣不实。
  • “换个号继续发同一套”：关联账号可能一起受限。
  • “找人代申诉 / 买解封”：本 Skill 只写官方入口，不写非官方渠道（非官方渠道无可靠来源，不推荐）。
  • “限流了继续发”：梯度处罚会升级，先停手、清理、走官方入口。

五、失败回退

  • 收到警告 / 限流：立即停发 → 清理违规内容 → 对照检查表逐项复核 → 确认无问题后再发。
  • 账号被封：不要注册关联小号继续发同一套违规内容 → 按第 7 步走官方申诉 → 等平台回复。
  • 第三方工具出问题：立即断开授权 → 检查该工具做了哪些写入操作 → 对照第 2 步复核。
  • 不确定某条规则：以平台官方规则为准，不要靠传言决定。
