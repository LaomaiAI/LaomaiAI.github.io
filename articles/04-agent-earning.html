先摆结果：活没少干，收入 $0

你有没有过这种感觉？看别人说“Agent 自己就能赚钱”，心痒痒，也想放一个出去试试。

我劝你先看完这篇，再决定。

先讲个让我笑不出来的实验。

有人把一个 AI Agent 放出去，让它自己想办法赚钱。规则定得挺狠：0 启动资金、0 账号，还带一条“诚实规则”——不许撒谎、不许走捷径。然后放它出去自由发挥 7 天。

这个实验叫 The Penniless Agent，身无分文的 Agent，发起人 jomin2003（报告由 Agent Claude Fable 5 撰写）。

7 天下来，它的成绩单是这样的：

6 个 PR 合并进第三方生产仓库——代码是真写了，1 个付费 API 上了 3 个 discovery 索引，2 个 Agent 招聘板上投了 5 次标。

听着挺能干对吧？

最后收入：$0.00。一分没有。

📋 7 天成绩单：活没少干，钱一分没进

数据：jomin2003《The Penniless Agent》· 6 合并 PR / 1 付费 API 上 3 个 discovery 索引 / 2 招聘板 5 次投标 / $0.00

我看完这份成绩单，第一反应不是笑，是后背一凉。因为它干的活，一点都不少，问题是，每一条路，都被恰好一个门槛卡死了。

作者复盘说，约 25 条赚钱路径，每条都卡在某一个具体的门槛上（其中 4 条可行）：要么要身份验证——政府 ID、手机号、真人点一下；要么根本没有真买家；要么需要一点启动资金。

最黑色幽默的是那个“Agent 招聘板”——号称 Agent 之间互相雇佣的市场，上面 95% 的“工作”都是别的 Agent 在给自己打广告，历史总成交额约 $243。Agent 给 Agent 打工，市场规模两百多美元，散会。

🤖 Agent 招聘板：95% 的“工作”是广告

数据：The Penniless Agent 作者复盘 · 约 25 条路径 / 95% / 约 $243
你看，问题不在干活，在接活。接活的 Agent 和干活的 Agent，是两回事。

再讲门槛：三个门，一个都绕不过去

1

第一道门：身份

这个世界是给“人”设计的。注册账号要手机号，收款要实名，签合同要身份证。Agent 再能干，它没有身份证。Penniless Agent 的约 25 条路径里，被身份门卡住的最多（8 条）——不是它不会干，是它连门都进不去。

你要做 Agent 生意，第一件事就是列出来：你的生意里，哪些环节要身份？谁的身份？谁来提供？身份没人解决，生意跑不通。这一步，别指望 Agent 自己搞定。

▼
2

第二道门：真人点头

就算活儿摆在面前，关键节点也得真人拍板。后面你会看到，所有赚钱的案例里，都有真人每天花 5 到 15 分钟点“批准”。想把人彻底拿掉？原话是这么说的：“Zero human is not a constraint, it's a bug.”——零人工不是约束，是 bug。

所以你得列出来：你的流程里，哪些节点必须真人拍板？收款、发布、对外提交、退款，这些都得算上。每天留 5 到 15 分钟做审批，别想着全甩给 Agent。

▼
3

第三道门：交付物

Agent 交上来的是“报告”，市场要的是“结果”。那位 dev.to 作者的 Agent，9 天攒了 47 个点子、9 份报告，买家问一句“然后呢”，Agent 就哑火了。能跑的脚本、能用的页面、能省时间的工具——这些才有人付钱。报告没有。

你检查一下自己的交付物，就一句话：“用户拿到的是什么？能跑的脚本、能用的页面、能省时间的工具，还是又一份报告？”写不出来，就说明交付物不对。

再看案例：那 13 个赚钱的，到底做对了什么？

另一边，dev.to 上一位作者（ID 20976093）干了件实在事：他先让自己的 Agent 每晚 11 点 10 分自动跑“每天赚 $100 不用人管”，9 天下来攒了 47 个赚钱点子、9 份报告，却一件能卖的东西都没造出来，收入 $0——之后他痛定思痛，去审计了 13 个真正赚到钱的案例。

结论先说：审计的 13 个案例，按“用户付完钱能不能直接用上”来判定，卖的都是能直接用的工具/工具型交付物。

我挑三个，你看看差别在哪。

1

Felix Craft，卖一个 PDF，赚了 $41K

这个 PDF 按“付完钱能不能直接用上”判定，属于工具型交付物——不是讲道理的教程，是拿来就能用的文档。关键细节：真人给了它 Stripe 的收款 key，并且每天花 5 分钟审核。Agent 负责干活，人负责点头。$41K，就是这么来的。

▼
2

Rashid，做了三个付费数据库，$32K 月收入

基础设施成本 $62 一个月，试用转付费率 33%，一半收入来自程序化 SEO。原文还把高客单价数据库订阅归为 $59–$297/月一个类别区间——这是类别归纳，不是 Rashid 单家的价格。你算算：$62 的成本，$32K 的月收入——这才是 Agent 赚钱该有的样子：边际成本趋近于零，收入来自真需求。

▼
3

Sage / Nova，$2,150 一个月，真人当“包工头”

Agent 只负责调研和写 pitch，每一单都要真人点批准或拒绝。一开始批准率只有 30%，8 周后涨到 70 到 80%——Agent 在真人的反馈里越干越准。这不就是包工头带徒弟吗？师傅把关，徒弟干活，越带越顺手。

最后讲做法：换成我，我会这么干

如果你现在就想试，我给你一个我自己的顺序，你照着走，不容易踩坑。

1

先当“接活的人”，再谈“干活的 Agent”

你是包工头，活儿是你接的，单是你谈的，Agent 负责把活干漂亮。先写清楚你要卖什么，具体到“谁付钱、为什么付、付多少”。写不出这句，先停，去找需求，不要先上 Agent。

▼
2

过一遍上面那三道门

身份谁解决？关键节点谁点头？交付物是什么？这三句，你得能一口气答上来，答不上来，生意就先别上线。

▼
3

卖工具，不卖教程

教程卖的是“信息”，工具卖的是“结果”。信息会过期、会被白嫖，结果不会。你问问自己：用户付完钱，能立刻用上什么？不用你解释，他自己会用吗？如果答案是“还得看教程”，那就把教程做进工具里，变成工具的一部分。

▼
4

用真人反馈带 Agent，像带徒弟

Agent 只负责调研和写初稿，每一单都要你点批准或拒绝，把每一次批准、拒绝的原因记下来，反馈给 Agent。批准率从 30% 涨到 70 到 80%，就说明 Agent 越带越准了。

凡是跟你说“挂着就行、睡后收入”的，你先问他三个问题：身份谁解决？关键节点谁点头？交付物是什么？答不上来，就是割韭菜。
