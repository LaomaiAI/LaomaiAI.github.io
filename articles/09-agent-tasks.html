怎么和 Agent 沟通，才能让它在你不在时接着干活？

2026-10-15 · AI包工头老麦

这篇讲什么：不在电脑前，怎么跟 Agent 交待任务、划好授权——什么活能交出去，什么活必须你点头。只讲通用方法，不讲“点哪里”，不绑定任何平台。

Skill（可直接用）：Agent 任务模式委托判断 · 交出去之前，先判能不能交 →

怎么读这篇：本文是通用方法总结，不针对某个平台，不引用任何平台的官方说明，也不承诺任何平台的具体功能。文中的判断方法、提示词模板、Skill 写法适用于任何支持任务模式的 Agent。

注：文中“花钱”仅指委托任务中的对外花钱授权边界——即下单、订座、签约、付款等对外动作是否允许 Agent 做，不指其他含义。

先说结论：它值钱的地方，是“你不在，它还在干活”

任务模式和普通聊天，根本区别就一个：聊天是你问一句它答一句，你在场；任务模式是你交出去，它接着干，你不在场。

说白了，任务模式值钱的不是“聊得更好”，而是“你不在，它还在干活”。

你把一件事交出去，合上电脑去开会、去吃饭、去睡觉。回来的时候，活已经干完了，你只负责验结果、做决定。

但这句话有个前提，很多人会漏掉——不是什么活都能这样交。边界不清的、结果不可逆的、代价大的，交出去就是给自己挖坑。

所以这篇不讲“点哪里”，只讲一个判断：什么活能交出去，什么活必须你点头。判对了，任务模式是帮你省时间的帮手；判错了，它就是帮你闯祸的帮手。

它到底变了什么：从“聊天”到“任务”

差别不在按钮在哪，而在你会不会交待任务。

聊天模式下，Agent 是“答题的”：你问，它答，一问一答，你全程在场。

任务模式下，Agent 是“干活的”：你交待一次，它按你的交待接着干，你不在场也能往下走。

这个变化带来的不是“更智能”，而是“更像委托”：你得像交待一个新同事一样，把事说清、把边界划清、把验法讲清。交待不清，它就得替你猜；猜错了，买单的是你。

能交的活，长什么样：四问全过，才交

判断方法很简单，交出去之前问自己四句话。四问全过，才交；有一问过不了，就先拆小，或者先让人点头。

能一句话说清要什么吗？

你让跑腿买东西，得说清买什么、多少钱封顶、买不到怎么办。说不清，跑腿就得替你猜。猜对了是运气，猜错了是你买单。

交任务也一样。你得一句话说清“要什么、不要什么、做到什么程度算完”。说不清的活，交出去就是让它替你猜。

错了能撤回吗？

错了能改的叫试错，错了改不了的叫事故。整理错了，重整一遍就行；发错了、下错单了，收不回来。凡是错了撤不回的，别直接交。

回来能快速验吗？

你回来得能一眼看出对错，不用重做一遍才知道它做得对不对。验起来比自己做还费劲的活，交出去不省时间，只是把活从“做”变成了“查”，还查不明白。

它会对外发出、花钱吗？

对外发、对外下单、对外提交、对外发布——这些动作先留给人。它能调用的工具再多，也不代表对外动作不用你点头。能调用什么是一回事，交什么出去是另一回事。

四问全过的活，长这样：整理、汇总、草稿、清单——把已有的东西理清楚，产出一份你回来能验的草稿。这是任务模式最不容易翻车的用法。

授权怎么写：交待任务时，三句话划清边界

四问是“能不能交”的判断，授权是“交到什么程度”的边界。交待任务时，把这三句话说清，Agent 就不用替你猜：

交什么：这次只做这一件事，做完就停，不顺手扩大范围。

到哪为止：只出草稿、只整理、不对外发出、不花钱；到需要对外动作的那一步，就停下来等你。

什么情况回来问我：遇到要求不明确、要花钱、要对外发出、要碰敏感信息的，一律停下，先问你，不自己做主。

这三句话就是授权的全部。没说清授权，等于把决定权一起交出去了——那不叫委托，叫甩锅。

授权要留出口：交待任务时就说清——进行中你能叫停、能改范围、能收回某项权限；遇到什么情况必须停下先问你。把“能叫停”写进交待里，而不是默认它有。交出去不是签卖身契，叫停的权力要留在你手里。

提示词怎么写：五要素，一次说清

任务模式好不好用，关键看提示词怎么写。好提示词有五个要素，缺一个，Agent 就得猜一个：

1. 做什么：一句话说清这件事是什么。不要写“帮我处理一下”，要写“把这三份会议记录整理成一份纪要草稿”。

2. 做到什么程度算完：验收标准写在前面。“整理成草稿，含结论、待办、负责人三部分，待办每条带上提出人”——这样它知道做到哪一步算完，你回来也知道怎么验。

3. 边界：不做什么。“只整理，不发给任何人；不改原文结论；不补充没提过的内容。”边界越清楚，它越不会自作主张。

4. 停下条件：什么情况回来问我。“遇到内容矛盾、缺关键信息、需要对外发出的，一律停下，先问我，不自己做主。”

5. 输出格式：回来怎么验。“按‘结论—待办—待确认’三段输出，待确认的单独列出来。”格式定了，你回来一眼就能验。

一个能直接用的模板：

帮我做【这件事】。做到【这个程度】算完。边界：【不做什么】。遇到【这些情况】停下，先问我，不要自己做主。输出格式：【怎么分段、怎么呈现】。

把【】填上，就是一条能交出去的提示词。填不上的地方，说明要求本身还没想清——先想清，再交。

Skill 怎么写：把判断写成可复用的检查表

提示词管一次委托，Skill 管一类委托。同一类活每个月都要交出去，就别每次重新想一遍，写成 Skill。

一个能用的 Skill 有四样东西：

什么时候用：一句话说清这个 Skill 解决哪类委托。比如“整理类委托：把已有材料整理成草稿，回来能验”。

检查表：把“四问”变成打勾项。交出去之前逐项打勾：说清要什么了吗？错了能撤回吗？回来能验吗？会对外发出、花钱吗？有一项打不上，就先拆小或先让人点头。

正反例：一个交对了的例子，一个交错了的例子。正例让人知道“这样写能成”，反例让人知道“这样写会翻车”。没有正反例的 Skill，只是空话。

失败回退：写清翻车了怎么办——“发现要求不明确，停下问我”“发现要对外发出，停下问我”“输出格式不对，重按格式出”。回退写在前面，出事才不用临时想。

写完 Skill，等于把“怎么交待任务、怎么划授权”固化下来了。下次委托同一类活，直接调这个 Skill，不用从零想起，Agent 也不用每次重新猜你的边界。

必须你点头的五种活：一律先停下

下面这五种，不管看起来多简单，都不直接交出去，必须你点头：

对外发出的——发给别人看的东西，消息、邮件、公告、帖子。发出去就收不回来，发之前必须你看一眼。

花钱的——下单、订座、签约、付款，任何涉及花钱和对外承诺的动作。哪怕它能下单订座，也不等于花钱可以不经过你。

碰敏感信息的——隐私、密码、财务数据、内部未公开信息。边界不清时，默认不交。

你自己都说不清要什么的——一句话说不清“要什么、不要什么、什么算完”，就别交。先把要求想清楚，再交；想不清楚，交出去也是白交。

错了你兜不住的——结果错了，代价是钱、名誉、数据丢失、法律风险。这类活，结果必须你验，决定必须你做。

记住一句话：你不在电脑前，不等于你不用负责。任务模式替你干活，不替你背锅。决定权在你手里，才叫委托；决定权交出去了，那叫甩锅。

交出去之前，30 秒，四问

把前面的判断压缩成四句话，交出去之前花 30 秒问一遍：

  1. 我能一句话说清要什么吗？——说不清，先想清楚，再交。
  2. 错了能撤回吗？——撤不回，先让人点头。
  3. 回来能快速验吗？——验不了，等于没省时间。
  4. 它会对外发出 / 花钱吗？——会，先让人点头。

四个都过，可以交；任何一个不过，先拆小，或者先让人点头。拆小的意思是：把大任务切成“先出草稿、我验完再往下走”的小步，而不是一次交到底。

三个坑，别踩

“能连很多工具，什么都能办。”错。能调用的工具多，不等于替你办事，更不等于对外动作不用你点头。能调用什么是一回事，交什么出去是另一回事。

“任务模式 = 不用管了。”错。任务模式是“你不在电脑前，它还在干活”，不是“你不用负责”。回来验结果、做决定，依然是你的活。交出去不管，叫甩锅，不叫委托。

“交待了任务，就不用管授权了。”错。交待任务只是说清“做什么”，授权是说清“做到哪为止、什么情况停下问我”。只交任务、不划授权，Agent 遇到边界就得替你做主，做错了还是你买单。

最后一句

任务模式不是让你变懒的工具，是让你把时间花在“只有你能做决定”的地方的工具。

整理、汇总、草稿——交出去。发出、花钱、担责——你点头。

判对了，你不在电脑前，它还在干活；判错了，你不在电脑前，它还在闯祸。区别不在工具，在判断。
